# Uppboð history data branch

This branch is maintained by the scheduled Uppboð workflow.

- `site/data/uppbod-history.sqlite` is the canonical SQLite archive.
- `site/data/history.json` powers the GitHub Pages search interface.
- `site/` is the exact directory deployed to GitHub Pages.

Do not edit generated data manually. Source code and workflow changes
belong on the repository's default branch.
